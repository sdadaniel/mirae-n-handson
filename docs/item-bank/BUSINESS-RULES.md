# item-bank-php 비즈니스 규칙 후보

대상: `legacy/item-bank-php/`. 진입점은 [ARCHITECTURE.md](ARCHITECTURE.md), 테이블 · 읽기/쓰기 위치는 [ERD.md](ERD.md) 를 따른다.

읽은 범위: `search.php`(731줄) · `register.php`(177줄) · `units.php`(48줄) 전체, `db/mariadb/init/01-schema.sql` 전체.

작성 기준
- 파일 경로는 `legacy/item-bank-php/` 기준이다. 스키마만 `01-schema.sql`(= `db/mariadb/init/01-schema.sql`)로 적는다.
- 확신도 **확실**은 조건문이나 SQL 로 확인한 것이고, **추정**은 이름 · 주석 · DB 설정으로 짐작한 것이다. 코드를 실행해서 확인한 규칙은 없다.
- 주석과 코드가 다르면 코드를 기준으로 규칙을 쓰고, 주석 내용은 비고에 남겼다.
- 근거가 주석뿐인 내용은 규칙으로 올리지 않고 5절에 모았다.

## 0. 범위 밖: 문항 수정

item-bank-php 에는 문항을 **수정**하는 화면도, `UPDATE` 문도 없다(ERD.md 3절, grep 0건). 그래서 수정 시 검증 규칙은 없다. 등록 규칙만 4절에 적었다.
