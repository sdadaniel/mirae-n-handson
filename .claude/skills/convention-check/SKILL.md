# 컨벤션 점검

## 원칙

- 코드를 직접 고치지 않는다. 보고만 한다.
- 근거 라인을 댈 수 없는 지적은 하지 않고 "확인 필요"로 남긴다.

## 1. 점검 대상 정하기

- 인자로 경로를 받았으면 그 경로(디렉터리면 그 아래 파일)만 본다.
- 인자가 없으면 아래 두 명령에 잡힌 파일을 합친다. `??`(아직 add 하지 않은 새 파일)도 포함한다.
  - `git status --porcelain`
  - `git diff --name-only HEAD`
- `modern/api/**/*.java`, `modern/web/src/**/*.ts(x)` 만 남긴다. 삭제된 파일, `legacy/`, `characterization/__snapshots__/` 는 뺀다.
- 대상이 없으면 "점검 대상 없음"이라고 쓰고 끝낸다.

## 2. 점검 항목 (예 = 통과)

| #   | 범위                  | 항목                                                                                          |
| --- | --------------------- | --------------------------------------------------------------------------------------------- |
| 1   | api 컨트롤러          | Repository 필드 · 생성자 인자, SQL 문자열이 없는가                                            |
| 2   | api 컨트롤러          | 메서드 반환 타입에 `@Entity` 클래스가 없고 `*Response` record 인가                            |
| 3   | api 전체              | 빈 `catch`, `System.out/err.println`, `e.printStackTrace()` 가 없는가                         |
| 4   | api 전체              | 인자 없는 `now()`(`LocalDateTime.now()` 등)가 없고 주입받은 `Clock` 을 쓰는가                 |
| 5   | api 전체              | 와일드카드 import 가 없고 모든 줄이 120자 이내인가                                            |
| 6   | web 전체              | `any`, `as unknown as`, `@ts-ignore` 가 없는가                                                |
| 7   | web `src/components/` | `fetch` 직접 호출, `dangerouslySetInnerHTML` 이 없는가                                        |
| 8   | web 전체              | `console.log` · `React.FC` · 클래스 컴포넌트가 없고, `eslint-disable` 같은 줄에 사유가 있는가 |

- 항목마다 Grep 으로 후보 줄을 찾은 뒤 Read 로 앞뒤 문맥을 보고 판정한다(주석 · 문자열 안의 일치는 위반이 아니다).
- 2번은 반환 타입 클래스를 Grep 으로 찾아 `@Entity` 여부를 확인한다. 끝까지 못 찾으면 "확인 필요".
- 한 항목에 규칙이 여럿이면 위반마다 어긴 규칙을 따로 적는다.

## 3. 출력 형식 (순서 고정)

### 판정 요약

- 점검 파일 N개, 위반 N건, 확인 필요 N건
- 항목별: `1 예 / 2 아니오 / 3 해당 없음 …` (대상 파일이 없는 항목은 "해당 없음")

### 위반 목록

| 파일:줄번호                             | 어긴 규칙     | 수정 방향                                             |
| --------------------------------------- | ------------- | ----------------------------------------------------- |
| `modern/api/.../ItemController.java:42` | #3 빈 `catch` | 로그를 남기고 다시 던지거나 도메인 예외로 바꿔 던진다 |

- 위반이 없으면 표 대신 "위반 없음"이라고 쓴다.
- "확인 필요" 항목은 표 아래에 한 줄씩, 왜 판정하지 못했는지 적는다.
